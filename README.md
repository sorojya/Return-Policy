# 返品についての特約事項
<p>返品についての特約事項<p>
<p>商取引法に基づく表記<p>
購入者は、提供する商品やサービスに対して不具合が問題や発生した場合、サービス提供者（当方）に対して返品を申し出ることが可能です。<br>
なお、返品対応可能な場合と、返品不可能な場合は下記のケースに応じます<br>
<p>返品が認められるケース<p>
1, 提供する商品の不具合、破損等商品説明に記載されていない問題が生じたとき<br>
2, ハードウェアおよびソフトウェアに問題が生じ、提供するサービスの完遂が難しいと判断される場合。<br>
3, 提供する商品やサービスに問題は生じていないが、購入者の都合によって返品を申し出るとき。<br>

<p>返品方法および送料の負担割合<p>
<p>＜返品方法＞<p>
返品を申し出た日から8日以内に、こちらが指定する宛先に、ゆうパックで発送ください。<br>
送料負担割合は以下の通りです。<br>

<p>＜送料負担＞<p>
1, 全額提供者負担・・・提供する商品の不具合、破損等商品説明に記載されていない問題がある<br>
2, 返送料購入者負担・・・提供する商品によらない問題（ソフトウェアダウンロードやソフトウェアシステムなど）が生じ、提供するサービスの完遂が難しいと判断される場合<br>
3, 全額購入者負担・・・商品やサービスに問題は生じていないが、購入者の都合によって返品<br>

<p>返品が認められないケース<p>
・商品に提供前に見られなかった不具合・破損等が認められるとき。<br>
・購入者がサービスの提供を受ける意思がないと判断される場合。（例：サービス提供を拒む、メッセージ等に応じない、など）<br>
・その他、提供者である当方が返品によって不利益を被る場合。<br>
